Cats — real photo slots
========================

Drop a real photo of any of the three cats in this folder and it replaces
the hand-drawn portrait automatically. No config, no rebuild, no code to
touch.

Name the file after the cat, exactly:

    olivia-benson.jpg
    meredith-grey.jpg
    benjamin-button.jpg

.jpg, .jpeg, .png, .webp and .avif all work. Missing one is fine — that
cat just keeps its illustrated portrait; nothing else breaks.

The photo fills the same circular, glowing frame the illustration sits in,
cropped to a square (object-fit: cover), so a roughly square, front-facing
photo works best.

A note on rights
----------------
There is no real photo of these cats that's legitimately free to embed —
every actual photo of them is Taylor Swift's own content or press/paparazzi
material, both copyrighted. Anything you put in this folder is your own
call to make. If you own the photo, or have a license or permission to use
it, it belongs here. Screenshotting someone else's Instagram post or a
tabloid photo and dropping it in doesn't change who owns it.

If you'd rather show a real Instagram post instead of a photo file, set
"instagram" on that cat in content/curated.json to the post's real URL —
see the note there. That uses Instagram's own embed widget (the same one
their "Embed" button generates), which is the sanctioned way to show a
real post rather than a copy of the image.
